🔑 還沒有 GitHub Token？第一次申請約 1 分鐘
  1. 先登入 GitHub，點下面「前往申請 Token」。
  2. 建立 Fine-grained personal access token。
  3. 在 Account permissions 將 Gists 設為 Read and write。
  4. 建立後立即複製 Token，貼到下方欄位即可。
↗ 前往 GitHub 申請 TokenGitHub 官方說明
